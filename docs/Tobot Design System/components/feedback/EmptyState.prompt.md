Estado vacío. Di qué hacer, no pidas perdón. El `mood` de TO acompaña el mensaje: `sleep` para apagado, `alert` para error, `idle` para vacío normal.

```jsx
<EmptyState mood="sleep" title="Este módulo está apagado" description="Enciéndelo y verás aquí lo que va registrando." action={<Button>Encender</Button>} />
```

Prohibido en facturación, pricing, errores de pago y tablas de datos: ahí va texto seco sin mascota (`mascot={false}`).
